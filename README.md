## 以下為格式測試  
<details>
<summary>可以不用管</summary>
  
  ### 格式表（注意#號後要加空格）  
  |格式|使用方法|快捷鍵(Mac)|
  |:---|:---:|---:|
  |`方框字`|\`words\`|`command` + `E`|
  |**粗體**|`**words**` or `__words__`|`command` + `B`|
  |*斜體*|`*words*` or `_words_`|`command` + `I`|
  |~刪除線~|`~words~` or `~~words~~`|
  |正常字<sub>下標字</sub>|`<sub>`words`</sub>`|
  |正常字<sup>上標字</sup>|`<sup>`words`</sup>`|
  |<ins>下划線</ins>|`<ins>`words`</ins>`|

  
  **換行**：句字最後加兩格空格  

  **引用**
  > words
  + `>` + words
  + `>` 在段落前空
    
  **代碼框**
  ```
    ```
      code
    ```
  ```

  **插入網址**
   + `[`words`](`網址連結`)` 
   + `[`words`][`網址名字`]` ，要另加上`[`網址名字`]:`+網址 在後面

  **插入圖片**
   + `![`words`](`網址連結`)` 
   + `![`words`][`網址名字`]` ，要另加上`[`網址名字`]:`+網址 在後面
     
  **github內文件網址**：在文件右上角點選<ins>setting</ins>，然後側欄點選<ins>Page</ins>
  
</details>
